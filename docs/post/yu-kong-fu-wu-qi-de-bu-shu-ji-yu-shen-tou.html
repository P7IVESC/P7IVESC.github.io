1.为 windows server 2008 安装 DNS 及 AD 域控制器
考虑到后续使用的便利性，现对域控服务器的 IP 地址进行指定，配置如下：

在“正向查找区域”点击鼠标右键，选择“新建区域”

1.2安装AD域服务


配置 Active Directory 域服务
开始菜单–>运行–>输入命令 dcpromo 点击“确定” 按钮

重启计算机
