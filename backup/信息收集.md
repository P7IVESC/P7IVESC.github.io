# 端口扫描

端口扫描非常重要，扫到服务如果没法访问，记得http和https来回切换访问

建议使用nmap和TscanPlus

```Bash
nmap -sS -Pn -n --open --min-hostgroup 4 --min-parallelism 1024 --host-timeout 30 -T4 -v -p 1-65535 -iL ip.txt -oX output.xml
```
